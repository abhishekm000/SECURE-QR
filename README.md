# 🔐 SecureQR — AES Encrypted QR Messaging

SecureQR is a browser-based encrypted messaging system that allows users to:

- Encrypt secret messages
- Generate secure QR codes
- Scan QR codes using camera or image upload
- Decrypt messages using dual-password protection

Built using:
- HTML
- CSS
- JavaScript
- AES-GCM Encryption
- PBKDF2 Key Derivation
- QR Code Technology

---

## 🚀 Features

✅ AES-256-GCM Encryption  
✅ Dual Password Protection  
✅ QR-Based Secure Sharing  
✅ Camera QR Scanner  
✅ Image Upload QR Scanner  
✅ Mobile Friendly UI  
✅ Compression using Pako.js  
✅ Real-time QR Decoding

## ⚡ How It Works

1. User writes a secret message
2. Message gets encrypted
3. Secure QR code is generated
4. Receiver scans QR
5. Receiver enters passwords
6. Message decrypts securely
